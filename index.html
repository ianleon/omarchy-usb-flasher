A small Quickshell app for Omarchy that flashes a bootable Linux ISO to a USB stick — and will not offer you the disk you booted from. Pick an image, pick a drive, confirm once, watch it verify.

dd is the right tool.
It is also the one that eats the wrong disk.

This is that command with the parts that matter made visible. Every guard below is in the repository, not in a screenshot.

Only removable drives are offered

Internal disks sit behind an explicit toggle, and any disk carrying /, /boot, /home, /var or swap cannot be selected at all.

One confirmation, spelled out

The drive's model, its size, its mount points, and the fact that all of it is about to be gone. Then Enter again.

Verified after the write

The stick is read back and its SHA-256 compared against the image. A silently bad stick is worse than a failed write.

One password prompt

Unmount, wipe, write, flush and verify all happen in a single privileged helper rather than five separate pkexec calls.

Four steps.
None of them a guess.

  1. 01

    Pick an image

    Images in ~/Downloads, ~/Desktop, ~/Documents, ~/ISOs and ~/Images are found automatically, newest first. Anything else goes in through Browse…

  2. 02

    Pick a drive

    The list refreshes every two seconds, so plugging the stick in after opening the app is fine.

  3. 03

    Confirm once

    Enter to flash, Enter again to confirm. The whole app works from the keyboard, including toggling verification and rescanning.

  4. 04

    Watch it verify

    The progress bar covers the write and both hash passes, so the bar reaching the end means the stick is good — not just written.

One privileged script.
You can read all of it.

flash.sh runs once, as root, through pkexec. It is 80 lines of bash and it does exactly this:

  1. unmounts every partition of the target and disables swap on it
  2. refuses to continue if the drive is smaller than the image
  3. clears stale partition signatures with wipefs -a
  4. writes the image with dd bs=4M oflag=direct conv=fsync
  5. flushes with sync and blockdev --flushbufs
  6. optionally SHA-256s the image and the first n bytes of the drive, and compares them

The write itself

dd if="$ISO" of="$DEV" bs=4M oflag=direct conv=fsync status=progress

Progress, throughput and the verification result come back over stdout as plain lines, so the GUI has no privileged code in it at all. Nothing is installed system-wide and no configuration is written.

Two ways in.
Both of them reversible.

As an Omarchy plugin it loads into the running shell as an overlay. As a standalone app it is an ordinary Quickshell window.

The recommended route. It loads into the running omarchy-shell as an overlay, and removing it deletes the plugin directory and its entry in shell.json — nothing else on the system is touched.

Install and enable

omarchy plugin add https://github.com/ianleon/omarchy-usb-flasher.git --enable --yes

Summon it

omarchy-shell shell toggle io.github.ianleon.usb-flasher '{}'

Bind it to a key

bind = SUPER SHIFT, U, exec, omarchy-shell shell toggle io.github.ianleon.usb-flasher '{}'

Remove it

omarchy plugin remove io.github.ianleon.usb-flasher --yes

For a plain Quickshell setup, or for hacking on it. install.sh symlinks the checkout into place rather than copying it, so editing the repository edits the installed app — and uninstall.sh removes the three symlinks and nothing else.

Clone and install

git clone https://github.com/ianleon/omarchy-usb-flasher.git
cd omarchy-usb-flasher
./install.sh

Launch it

omarchy-usb-flasher

Remove it

./uninstall.sh

Tested on Omarchy 4.0.0.alpha with Quickshell 0.3.1, writing a Linux Mint ISO to a USB stick that then installed cleanly. It needs polkit with an agent running, util-linux, coreutils and bash — all stock.
